# LoanSMSScanner 💰

**Smart SMS Loan Tracker & Debt Strategist for Android**

An Android app that automatically scans your SMS inbox for loan-related messages from popular Kenyan financial services, detects outstanding loans, calculates totals, and gives you clear, actionable strategies to pay them off — all in a clean, modern interface.

> **Note:** This repository currently contains only the project README. Full source code is coming soon.

---

## 🎯 What It Does

1. **Scans SMS** for loan messages from:
   - M-Shwari
   - KCB M-Pesa
   - Fuliza
   - Equity Bank
   - Other banks & mobile lenders

2. **Identifies** which loans are still unpaid (recent & outstanding)

3. **Calculates** the total outstanding debt across all sources

4. **Suggests** strategic, easy-to-follow repayment plans so you can tackle debt step by step

---

## 📱 Planned Features

- Beautiful, simple, and intuitive UI (not just plain text)
- Automatic SMS parsing for loan disbursements & repayments
- Outstanding loan summary with totals
- Smart repayment strategies (prioritize high-interest, smallest first, avalanche/snowball methods, etc.)
- Visual progress tracking
- Privacy-first: SMS data stays on your device

---

## 🛠️ Tech Stack (Planned)

- Kotlin
- Jetpack Compose (modern Android UI)
- Android SMS permissions (READ_SMS)
- Local database (Room) for storing parsed loans
